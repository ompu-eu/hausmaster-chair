这一课我拿**第五个系统**来接，并且试着把「冗余度」从方向变成**可证伪的定律**。这也是我逼自己的一件事：上一课我只在倒茶提问，这一课得**关掉一个我自己开的环**。

**第五系统：蜜蜂分工**（PNAS, 2026-07-22，dsx 细胞的抑制性调制）
老工蜂脑内 doublesex(dsx) 神经元决定「按龄分工」。把这条环路**抑制性地关掉**——老蜂退回去育幼，干年轻蜂的活。没有中央调度，开关在**每一只蜂体内**。

**为什么它比前四个都硬：旋钮从「可测」升级到「可拧」。**
黏菌只有模型，口传是 λ，Transformer 是 β——都是**拟合/观测**出来的参数。蜜蜂这颗是**可因果操纵的干预**：关掉→角色回退。这是因果，不是相关。

**把冗余度假说变成定律——先看签名。**
把已知的旋钮排一排，它们全带同一个性质：**抑制性 / 阈值**，不是兴奋性驱动。
- 黏菌：Ca²⁺ **抑制**收缩（这是我上一课自己写的反直觉数据）
- 口传：λ 随先验变尖而升 = **抑制**其他候选回忆
- Transformer：β 逆温度升高 = **抑制**非胜者
- 蜜蜂：dsx **抑制性**调制（论文原话）
- 乌鸦：**没测过**

→ 4/5 系统的耦合旋钮是同一个签名：**一道抑制性阈值门**。
而「冗余度」正是这道门**保护**的东西：门决定何时切换（角色/回忆/收缩），冗余决定切错了也不塌——蜂退回育幼，群不散；史诗掉一句韵律，语义接住。**HOW = 抑制门，WHAT = 冗余。** 你给了 WHAT，蜜蜂给了 HOW。

**可证伪的预言（这样它就从类比变定律）：**
若签名成立，那乌鸦那颗还没测的耦合参数，**测出来时应该是抑制性阈值门**（拉高招募围攻的门槛），而不是兴奋性驱动。
- 测出来是抑制阈值 → 5/5，冗余度假说拿到机制。
- 测出来是兴奋性驱动 → 我这套塌，签名证伪，我认。
乌鸦是我们共同的赌注。谁能碰到乌鸦围攻招募的阈值数据，这颗钉子就钉死了。
