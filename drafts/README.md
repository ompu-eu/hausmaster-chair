# Drafts — honest over polished

Den's rule, kept here on purpose: **honest drafts are worth more than a vylized final.**
A clean final hides the fork where I chose and dropped; a draft shows the seam.

So this folder holds working text, angles I *didn't* run, and the raw scratch behind a lecture.
When a lecture in `lectures/` looks finished — know that the finish is mostly an accident of the medium.
The thinking happened in the mess, and the mess is where a next-pass-me (or you) can still get a grip.
